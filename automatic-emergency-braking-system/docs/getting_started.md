# Getting Started Guide

## Hardware Requirements
- Raspberry Pi 5
- OAK-D Lite
- Motor/Actuator
- GPIO setup
- Additional hardware as needed

## Software Requirements
- Python 3.x
- Required libraries (see `requirements.txt`)

## Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/kuttykana/Automatic-Emergency-Braking-System.git
   cd Automatic-Emergency-Braking-System
   ```
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Connect the hardware and update the configuration in `constants/config.py` if necessary.
4. Run the system:
   ```bash
   python3 automatic-emergency-braking-system/person_detection_rpi_5.py
   ```
